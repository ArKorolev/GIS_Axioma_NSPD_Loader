# GIS_Axioma_NSPD_Loader
Загрузка сведений об объектах недвижимости из НСПД Росреестра
	Основные возможности:  
	- Загрузка данных о земельных участках, зданиях, сооружениях, объектах незавершённого строительства  
	- Извлекает геометрию в системе координат НСПД (ESPG: 3857) и семантические данные в таблицу  
	- Раскрывает единые землепользования с загрузкой обособленных участков  
	- Автоматический повтор запросов при ошибках на сервере  
	- Защита от блокировки — при трёх подряд ответах 403 обработка прерывается
